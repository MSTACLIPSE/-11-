## 📦 What's inside

| Folder | Description |
| --- | --- |
| [`komorebi/`](./komorebi) | Tiling window manager config (`komorebi.json`, `applications.json`) |
| [`yasb/`](./yasb) | Status bar — styles, widgets, config |
| [`windhawk/`](./windhawk) | Windhawk mods & their settings |
| [`cava/`](./cava) | CAVA audio visualizer config |
| [`spotify/`](./spotify) | Spicetify theme + extensions |
| [`discord/`](./discord) | Vencord / BetterDiscord theme & plugins |
| [`terminal/`](./terminal) | Windows Terminal + PowerShell profile |
| [`wallpapers/`](./wallpapers) | Wallpapers used in the rice |
| [`screenshots/`](./screenshots) | Preview images |

## 🧰 Stack

- **[Komorebi](https://github.com/LGUG2Z/komorebi)** — tiling window manager
- **[YASB](https://github.com/amnweb/yasb)** — status bar
- **[Windhawk](https://windhawk.net/)** — Windows customization mods
- **[CAVA](https://github.com/karlstav/cava)** — audio visualizer
- **[Spicetify](https://spicetify.app/)** — Spotify theming
- **[Vencord](https://vencord.dev/)** — Discord client mod
